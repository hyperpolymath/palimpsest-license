=== 2.1 Receipts and grade

Each leg's receipt is its job in the `Warrant levels` workflow on the
commit in question, with the versions and invocations of §2.2. The Proof
Witness Grade (`pwg`) of each theorem is derived from those receipts as
§8.2 says: `PWG-3` with the Agda job green, `PWG-2i` with one recheck job
green as well, `PWG-2ii` with both. It is never carried from one commit to
the next (§8.4), so this file records the derivation, not a grade.

First receipts: `Warrant levels` run 42623338797, on #190's merge commit
`b6614d2f63d4adb49b38318a9c7a8e12b6af6b34`. Agda 2.6.4.3 under the §2.2
invocation: the module, four expected rejections and the control. Coq
8.18.0 (`/usr/bin/coqc` digest verified): six statements closed under the
global context; the `Admitted` control reported. Lean 4.35.0 (commit
`eb6cafb7290e8bd5f2937522d8d804f58f02bafc`, archive digest verified): six
declarations with no axioms; the `sorry` control reported. On that commit
each of the six theorems derives `PWG-2ii`, with no axioms. The Lean leg's
first kernel check was this CI run: the session that wrote it could not run

Census (§8.4), on `main` before these changes merge: 6 theory theorems;
`PWG-1` 0, `PWG-2ii` 0, `PWG-2i` 0, `PWG-3` 0, `ungraded` 6. It moves only
with a receipt on `main`.

== 2.2 Correspondence (§2.2)

Each target restates the Agda statements; the comparison below was made by
reading the three sources side by side, not by a round trip.

[cols="1,3",options="header"]
|===
|Point |Agda, and how each target matches it

|Source revision
|The commit of this file. epistemic-types at
`dcd464839333bc83e55c7ddf44ade7cc83426a99`.

|Checkers
|Agda 2.6.4.3 (CI; `agda-bin=2.6.4.3-1+b2`), Coq 8.18.0
(`coq=8.18.0+dfsg-1build2`), Lean 4.35.0.

|Invocation
|`scripts/check-agda.sh`: `--safe --without-K --cubical-compatible
--exact-split --no-sized-types --no-guardedness --no-libraries
--ignore-interfaces --double-check -W error -W noUnsupportedIndexedMatch`,
plus the span audit. `scripts/check-rocq.sh`: `coqc -q`.
`scripts/check-lean.sh`: `lean`.

|Records
|epistemic-types' `Warrant` (one field `Evidence : Set`), `Epi` (`warrant`,
`evidence`), `SoundWarrant` (`warrant`, `sound : Evidence → A`) and
`sound-epi` are restated field for field in both targets, since
epistemic-types has no Rocq or Lean leg. Rocq prefixes `Epi`'s fields
(`epi_warrant`, `epi_evidence`) because its record fields are global.

|Universes
|Agda uses `Set` (`wℓ = lzero`), the records living in `Set₁`. Rocq uses
`Set` with the records in `Type`; Lean uses `Type` with the records in
`Type 1`. The three `no-…` statements quantify over `Set`/`Type` in every
prover. That matters: a hypothesis quantified over a larger universe is
stronger, so the refutation would be weaker.

|Equality
|Agda's `_≡_` is `Set`-valued; Rocq's `eq` and Lean's `Eq` are `Prop`-valued.
The statements use equality only on `Bool` (`verify pk m σ ≡ true`), where
equality is decidable and all three agree on what is inhabited, and between
types (`Evidence … ≡ Verified pk m`), proved by reflexivity in all three.
The difference changes no claim made here.

|Σ
|Agda's `Σ Signature (λ σ → …)`; Rocq's `{ s : Signature & … }` (`sigT`);
Lean's `Σ' σ : Signature, …` (`PSigma`, its second component being a
`Prop`).

|Parameters
|Agda's module parameters are Rocq `Section` variables, abstracted in
declaration order, and explicit Lean arguments.

|Names
|`example` is `ToyModel.toyExample` in Lean, where `example` is a keyword.
Type-valued Lean results are `def`s, `theorem` being for propositions.

|Residual assumptions
|None beyond the stated hypothesis `unforgeable`. The Rocq and Lean gates
require every reported statement to be axiom-free and check that a planted
escape hatch is reported (`Admitted` in Rocq, `sorry` in Lean). In Agda,
`--safe` refuses a postulate anywhere in the import cone; the Agda gate has
no planted postulate control of its own yet.
|===

== 3. The Agda import cone (§1.1)

epistemic-types is checked, not assumed. Root module
`proofs/agda/Provenance/Warrant.agda`; cone `EpistemicTypes.Warrant`,
`EpistemicTypes.EchoBridge`, `EpistemicTypes.Base` at `dcd4648`; flags as in
§2.2; no standard library (`--no-libraries`); zero postulates (`--safe`
refuses them).

Agda cannot yet compute two indexed matches in `EchoBridge.agda` (lines
156–157 and 168–169) under Cubical transport. The proofs check; no Cubical
transport-computation claim is made for those two definitions. They are
upstream's own reviewed spans, and `check-agda.sh` fails if the set of
warned spans changes.
